# fuehrerschein-helfer
Führerschein-Helfer: Was kostet der Pkw-Führerschein mit den Preisen der eigenen Fahrschule (inkl. Prüfungen, Nebenkosten, Durchfall-Risiko), lohnt sich Warten auf die Reform 2027, wie lange sparen und ab wann anfangen. Werte lassen sich über den Hash vorbelegen, z. B. `#warten?std=75&uebung=25&plus=6`.
